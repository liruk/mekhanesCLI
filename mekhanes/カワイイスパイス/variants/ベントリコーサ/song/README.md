# 尽き得ぬイドのネペンテス

対ベントリコーサ戦を、ベントリコーサ本人の視点から歌うバトルソング。Suno v6向けの英語歌詞と最終Style。Styleは2026年9月25日のユーザー指定で確定。音源はこのフォルダに未収録。

## 曲の中心

いおどを自ら失わせたことを悔い、なお飢え続ける彼女の独り言。ルノフェットやピュリファイアは側にいても彼女の関心に入らない。歌の終わりにも飢えと悲しみは残る。

激しい戦闘は身体への衝撃、遠い叫び、旋回する鎌、壁を破る根として知覚される。対戦相手への挑発や勝利への欲望は歌わせない。呼びかけの相手は一貫していおど。伴奏と戦闘は激しく、彼女の内面は喪失と飢えに留まる。

歌詞は英語。「I'm sorry」と「I'm still hungry」を繰り返しの中心に置く。タイトルは日本語の「尽き得ぬイドのネペンテス」を維持する。歌詞内では「Nepenthes, never full」を反復句とし、いおどの名前は「Iodo」と表記する。

Verse 2の冷めた夕食を温めようとする場面は、料理が得意でいおどを育てていた元の彼女から着想した記憶の情景。戦闘の衝撃で現在へ戻る構成とする。新たな事件の設定を確定するものではない。

## 最終曲調

- 悲しげなピアノの旋律を曲全体に交えたGothic DnB。
- 重いディストーションギターとシンコペーションの効いたドラムで、エクストラボス戦の激しさを出す。
- 英語のクリーンな女性ボーカル。悲痛な歌声と短調の旋律で、深い喪失と止まらない飢えを表す。
- Styleは主要な楽器・歌声・感情に絞り、BPM・拍子・細かな展開指定は外す。
- 想定尺は4分前後。実際の旋律と歌唱の間に合わせて調整する。

## 制作入力

- lyrics.txt: 英語の歌唱用歌詞。セクションタグ以外の指示は入れない。
- style.txt: Suno v6へ渡す最終Style。ユーザー指定の英文をそのまま保存。
- versions/: バラード版の英語初稿を保存。現在の制作入力は直下のlyrics.txtとstyle.txt。
- タイトル読み案: つきえぬイドのネペンテス。
- テンポ・拍子・楽器・構成は生成への要望。自然言語指定だけでの正確な再現は未検証。
- この作業では音源生成・試聴を実施していない。歌いやすさ、発音、音色は実音で確認する。
