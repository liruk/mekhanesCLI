# コーポ・アレス

軍産企業。人類の適応に伴い誰も魔術を使えなくなった結果、この世界のマナの巡りは滞っている。そのため、多種多様かつ強力な魔物が現れるので、その対処を専門とする会社が必要となった。
プロダクトには無骨なデザインが多い。
ルノフェット（ルノフェン）はここに所属している。

## 滑走艇と軍艦

単独潜入から部隊輸送、複数の母艦の指揮まで、用途に応じた軍用艇を製造している。

| 製品 | 規模・用途 | 特徴 |
| --- | --- | --- |
| スカウト | 単独潜入用の小型艇 | マナ包絡の下に光学迷彩を備える。通信をすべて遮断して探知を困難にできる。 |
| パルチザン | 乗員二名までの遊撃用小型艇 | 探知されにくさと簡素な実弾砲を両立し、敵陣深くの指揮官を狙う。 |
| ファイター | 定員五名の分隊用小型艇 | 本格的な実弾砲と、それには劣るもののマナ砲を備える。最低限の防御力を持ち、宇宙生物への対処にも用いる。 |
| ナイト | 百名から二百名の中隊用中型艇 | パルチザンやファイターの母艦。企業の依頼で出動する際は、この艇を一単位として取引する。 |
| ウォーロード | 千名程度の大型艇 | 複数のナイトを指揮する指揮官の拠点。滑走艇よりも軍艦として扱われることが多い。 |

各艇の詳細は、[滑走艇](../glidecraft.md)を参照。
