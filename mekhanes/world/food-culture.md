# 星間社会の食品事情

売り場に「模造」と札の掛かった羊肉がある。安物を期待して値段を見ると、隣の牧場育ちの羊より高い。メーカネース・ナーヴィスの食品は、食材ができるまでの工程によって、オーガニック食品、模造食品、工業食品に大別される。三つの呼び名から、夕食の予算や味の良し悪しまで読み取るのは難しい。

## オーガニック食品

野菜なら土に植えて育て、食肉なら家畜を育てて屠る。こうした旧来の農畜産で得た食材がオーガニック食品にあたる。農場では遺伝子組み換えも日常的に行われる。栽培したキャベツが人の胴ほどに育とうと、売り場は青果のままだ。

最大手は[ネイチャーダイエット](<mega-corps/ネイチャーダイエット.md>)傘下のネイチャーオーガニック。生鮮品を星から星へ運べば、売値に運賃が響く。そこで、都市と呼べる規模の星にはたいてい支部を置き、現地で食材を生産している。遠くの星へ越しても、食べ慣れた銘柄のリンゴが地元産として手に入る。

| 主力商品 | 食卓での扱い |
| --- | --- |
| 赤い頬 | 甘みの強い大玉リンゴ。生食向きで、切り分けるだけで一皿になる。 |
| 黄色い三日月 | 種なしのバナナ。潰してペーストにしたものは定番の離乳食。 |
| コウノトリの恵み | 一玉が六十センチにもなる巨大キャベツ。大鍋で何十人分も煮込む食堂には都合のよい大きさだ。 |

## 模造食品

オーガニック食材の食感を模して作る食品。何を、どこまで再現するかによって、同じ分類に価格も評判も異なる製品が並ぶ。

[インポスターレーション](<mega-corps/インポスターレーション.md>)は「骨の釘からラーメンを生み出す」と評されるほど安く合成食料を供給する。同社はオーガニック以上の栄養価を謳い、実際にその製品だけで暮らせる。長らく「味に喜びはない」といわれてきたが、星間暦3824年ごろに方針転換を発表。味は少しずつ改善している。

一方、バイオテック最大手の[ネクストジェン・グロウ](<mega-corps/ネクストジェン・グロウ.md>)は、羊肉を作るのに羊一頭を組み上げる。羊の組成をもとに個体を培養し、生きた羊を解体して肉を取る。個体そのものを培養して再現したため、皿に載る肉は模造食品に数えられる。味を買う客の中には、牧場の羊を超えたと評する者さえいる。

## 工業食品

安価な模造食品にも手が届かない低層の市民にとって、工業食品は日々の糧になる。安全性はある程度確かで、うまみ成分も適度に加えてある。任地で手早く食事を済ませたいエージェントも携行する。

[ソーラー・サプリ](<mega-corps/ソーラー・サプリ.md>)は太陽光を利用したサラダやスムージーで知られるが、工業食品の売り場で同社の名を代表するのは「デントコーンバー」だ。こちらは疑似太陽光の下で効率よく育てた家畜グレードの穀物を、人間がそのまま食べられる棒状に加工したもの。鍋も食器も要らず、任務先では袋を開ければ一食になる。

[サステイナブル・フィーズ](<mega-corps/サステイナブル・フィーズ.md>)は食品ごみを回収し、有害物質を除いて再び食品に加工する。「フードサイクルシステム」から生まれる同社の製品には「リサイクルペレット」や「エコスナック」がある。原料の来歴を知ってためらう人もいるが、味の評判はよく、栄養価も高い。低所得層を診る病院では、同社の食品を入院患者の食事に採用することもある。

## 一玉のキャベツをどう食べるか

たとえば街の食堂が「コウノトリの恵み」を一玉仕入れたとする。昼は葉を刻んでインポスターレーションの安いラーメンに山盛りにする。夜は大きな外葉でネクストジェン・グロウの羊肉を包んで煮込み、一皿ずつ値をつける。同じ畑の一玉が、昼には安さを、夜には大きな葉を破らず巻けることを買われている。

一方、その店の常連でも、任務中ならポケットのデントコーンバーで昼を済ませるかもしれない。同じ一本でも、その日の仕事に合わせて選んだ者と、給料日までそれでつなぐ者とでは、夕飯を選べる余地が違う。
